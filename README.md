# Замеритель скорости интернета

Консольная программа десять раз последовательно скачивает указанный HTTP(S)-ресурс,
дожидаясь полного ответа на каждый запрос. По фактически полученным данным она
выводит среднее время запроса, общий объём и среднюю скорость загрузки.

## Требования

- Python 3.11 или новее;
- доступ к выбранному HTTP(S)-ресурсу.

Runtime-зависимостей нет.

## Установка и запуск

Установить проект в виртуальное окружение:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e ".[dev]"
```

Запустить измерение:

```bash
internet-speed-meter https://example.com/large-image.jpg
```

Либо запустить пакет напрямую из установленного проекта:

```bash
.venv/bin/python -m speed_meter https://example.com/large-image.jpg --timeout 60
```

`--timeout` задаёт предельное время каждого запроса в секундах. При сетевой ошибке
серия прекращается, а программа возвращает ненулевой код завершения.

## Методика расчёта

- время запроса включает получение ответа целиком;
- среднее время — сумма длительностей десяти запросов, делённая на 10;
- объём определяется по реально прочитанным байтам, а не по `Content-Length`;
- 1 МБ равен 1 000 000 байт;
- скорость равна общему объёму, делённому на суммарное время загрузок.

## Разработка

Запуск тестов:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Статический анализ:

```bash
.venv/bin/ruff check src tests
```

Сборка пакета:

```bash
.venv/bin/python -m build
```

этими файлами. Для публикации используются только временные права `GITHUB_TOKEN`.
