# Project Codex Instructions

## Scope

- Эти правила действуют для всего репозитория.
- Они дополняют глобальные инструкции Codex; при конфликте применяются правила из этого файла.

## Language

- Общение с пользователем и проектная документация ведутся на русском языке.
- Комментарии и docstring в исходном коде пишутся на русском языке.
- Исходный код, технические идентификаторы и сообщения коммитов пишутся на английском языке.

## Implementation

- Использовать Python 3.11 или новее и по возможности стандартную библиотеку.
- Сохранять CLI простым, предсказуемым и пригодным для автоматизации.
- Сетевые ошибки и неверный пользовательский ввод должны завершать программу с понятным сообщением и ненулевым кодом возврата.
- Расчёты скорости и единицы измерения должны быть явно определены и покрыты тестами.

## Quality

- Для изменённого поведения добавлять или обновлять тесты на `unittest`.
- Перед завершением запускать целевые тесты, проверку CLI и сборку пакета.
- Не добавлять runtime-зависимости без необходимости.
- Не изменять `TASK_DESCRIPTION.md`.

## CI/CD

- CI должен запускаться для pull request и push в основную ветку, проверять тесты и сборку.
- CD должен собирать дистрибутивы и создавать GitHub Release для тегов формата `v*`.
- Публикация не должна требовать хранения долгоживущих секретов в репозитории.
